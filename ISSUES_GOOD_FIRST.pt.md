# Boas primeiras tarefas

[English](ISSUES_GOOD_FIRST.md) · [Română](ISSUES_GOOD_FIRST.ro.md) · [Français](ISSUES_GOOD_FIRST.fr.md) · [Italiano](ISSUES_GOOD_FIRST.it.md) · [Español](ISSUES_GOOD_FIRST.es.md) · **Português** · [Deutsch](ISSUES_GOOD_FIRST.de.md) · [Magyar](ISSUES_GOOD_FIRST.hu.md)

- [ ] Definir a lista de línguas ISO 639-3 e acrescentar um índice `languages.json`
- [ ] Acrescentar 50 palavras básicas (números, família, corpo) para o arromeno (rup)
- [ ] Acrescentar 50 palavras básicas para o meglenoromeno (ruq)
- [ ] Acrescentar 50 palavras básicas para o romani (rom), com um campo de dialeto
- [ ] Acrescentar os campos opcionais `dialect` e `orthography` ao esquema
- [ ] Construir a página de pesquisa offline com correspondência insensível aos sinais diacríticos
- [ ] Acrescentar suporte de gravações de áudio (opus, menos de 50 KB por palavra) e um guia de gravação
- [ ] Acrescentar exportação para Anki/TSV para quem aprende
- [ ] Escrever um guia para falantes sem formação técnica (com capturas de ecrã)
- [ ] Acrescentar um verificador que avise de entradas duplicadas

Cria-as todas no GitHub com `scripts/create_issues.sh` (requer a CLI `gh`).
