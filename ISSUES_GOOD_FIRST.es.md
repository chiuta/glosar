# Buenas primeras tareas

[English](ISSUES_GOOD_FIRST.md) · [Română](ISSUES_GOOD_FIRST.ro.md) · [Français](ISSUES_GOOD_FIRST.fr.md) · [Italiano](ISSUES_GOOD_FIRST.it.md) · **Español** · [Português](ISSUES_GOOD_FIRST.pt.md) · [Deutsch](ISSUES_GOOD_FIRST.de.md) · [Magyar](ISSUES_GOOD_FIRST.hu.md)

- [ ] Definir la lista de lenguas ISO 639-3 y añadir un índice `languages.json`
- [ ] Añadir 50 palabras básicas (números, familia, cuerpo) para el arromanés (rup)
- [ ] Añadir 50 palabras básicas para el meglenorrumano (ruq)
- [ ] Añadir 50 palabras básicas para el romaní (rom), con un campo de dialecto
- [ ] Añadir los campos opcionales `dialect` y `orthography` al esquema
- [ ] Construir la página de búsqueda sin conexión con coincidencia insensible a los signos diacríticos
- [ ] Añadir soporte de grabaciones de audio (opus, menos de 50 KB por palabra) y una guía de grabación
- [ ] Añadir exportación a Anki/TSV para quien aprende
- [ ] Escribir una guía para hablantes sin formación técnica (con capturas de pantalla)
- [ ] Añadir un comprobador que avise de las entradas duplicadas

Créalas todas en GitHub con `scripts/create_issues.sh` (requiere la CLI `gh`).
