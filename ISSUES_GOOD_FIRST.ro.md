# Sarcini bune pentru început

[English](ISSUES_GOOD_FIRST.md) · **Română** · [Français](ISSUES_GOOD_FIRST.fr.md) · [Italiano](ISSUES_GOOD_FIRST.it.md) · [Español](ISSUES_GOOD_FIRST.es.md) · [Português](ISSUES_GOOD_FIRST.pt.md) · [Deutsch](ISSUES_GOOD_FIRST.de.md) · [Magyar](ISSUES_GOOD_FIRST.hu.md)

- [ ] Definește lista limbilor ISO 639-3 și adaugă un index `languages.json`
- [ ] Adaugă 50 de cuvinte de bază (numere, familie, corp) pentru aromână (rup)
- [ ] Adaugă 50 de cuvinte de bază pentru meglenoromână (ruq)
- [ ] Adaugă 50 de cuvinte de bază pentru romani (rom), cu câmp pentru dialect
- [ ] Adaugă câmpurile opționale `dialect` și `orthography` în schemă
- [ ] Construiește pagina de căutare offline cu potrivire insensibilă la diacritice
- [ ] Adaugă suport pentru înregistrări audio (opus, sub 50 KB pe cuvânt) și un ghid de înregistrare
- [ ] Adaugă export în Anki/TSV pentru cei care învață
- [ ] Scrie un ghid pentru vorbitori fără pregătire tehnică (cu capturi de ecran)
- [ ] Adaugă un verificator care avertizează asupra cuvintelor-titlu duplicate

Creează-le pe toate pe GitHub cu `scripts/create_issues.sh` (cere CLI-ul `gh`).
